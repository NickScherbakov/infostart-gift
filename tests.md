# Тестовые сценарии и учебные задания

### Сценарий 1. Базовая проверка «старичков»
1. Установите период перезапуска: `30` минут.
2. Создайте в тестовой среде процессы с возрастом 10 и 90 минут.
3. Запустите проверку для тестового профиля:
   ```bash
   /opt/admincluster/admincluster_run.sh --profile test --dry-run
   ```
4. Убедитесь, что процесс старше 30 минут без активных соединений помечен флагом `ФлагСтаричок = true`.

### Сценарий 2. Процесс с активными соединениями
1. Создайте процесс с возрастом > периода и количеством соединений > 0.
2. Запустите проверку и dry-run перезапуска.
3. Убедитесь, что такой процесс исключен из перезапуска, а в логах зафиксировано наличие соединений.

### Сценарий 3. Проверка системы алертов
1. Настройте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `ALERT_EMAIL` в `/etc/admincluster/config.conf`.
2. Запустите тестовую отправку уведомления:
   ```bash
   /opt/admincluster/admincluster_notify.sh --profile test --file example_report.csv
   ```
3. Проверьте доставку сообщения в Telegram и почтовый ящик.

### Сценарий 4. Автоматизация через systemd
1. Активируйте таймер:
   ```bash
   sudo systemctl enable --now admincluster-monitor@test.timer
   ```
2. Проверьте журнал:
   ```bash
   journalctl -u admincluster-monitor@test -f
   ```
